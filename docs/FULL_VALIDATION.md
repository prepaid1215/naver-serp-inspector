# SERP Lens v1.9 — 5단계 전체 검증 절차

## 통합 검사 버튼

설치된 확장프로그램 → **1~5단계 전체 검증하기** → **전체 단계 다시 점검**.

내 브라우저에 실제 저장된 자료가 얼마나 있는지 한 화면에서 확인하며
**5단계 검증 보고서 JSON 저장**으로 근거와 판정 결과를 내려받습니다.

이 버튼으로 네이버를 자동 검색하지 않습니다. 수집 자료가 없는 항목은 미검증으로 표시합니다.
GitHub CI 통과와 현장 근거 확보는 서로 다른 검사입니다.

## 단계별 판정 기준

| 단계 | 구현 상태 | 현장 자료 확보 기준 |
|---|---|---|
| 1. 검색 결과 수집·이력 | 기존 기능 | 검색어·기기 조합 2개 이상과 SHA-256 원본 근거가 있는 검색 기록 2건 이상 |
| 2. 실제 문서 본문 | 기존 기능 | 제목과 본문 60자 이상을 포함한 직접 방문 문서 3건 이상 |
| 3. 노출 패턴 관측 | 기존 기능 | 3개 이상 검색어·기기 조건과 비교쌍 최소 8개/조건 3개를 충족한 관측 특성 1개 이상 |
| 4. 변경 전후 실험 | 기존 기능 | 동일 검색어·기기의 수정 전후 수집 2회씩, 같은 문서 유형의 대조군 1개 이상, 상대 변화 계산 가능 |
| 5. 실제 화면 검수 | v1.8 기능 | 데스크톱 너비 PC 검색 1건과 모바일 너비 모바일 검색 1건을 각각 직접 화면 검수 완료 |

**주의:** 위 기준은 연구 준비 상태를 분류하기 위한 최소한의 운영 기준입니다.
정확도 인증, 통계적 유의성, 네이버의 로직 복원 판정이 아닙니다.

## 한 번에 실행하는 자동 검증

GitHub PR을 만들면 다음 두 자동 작업이 수행됩니다.

1. **Validate web parser**: 전체 JavaScript 검사·단위 테스트·Chrome 브라우저 오프라인 E2E 테스트
2. **Package Chrome and Edge extension**: 동일 JS 테스트를 통과한 패키지를 ZIP으로 생성하여 GitHub Actions에 보관

브라우저 E2E는 검색 수집, 본문 비교, 패턴 관측, 대조군 실험, 스크린샷 위치 검수,
5단계 검증판에서 JSON을 내보내는 과정을 모의 자료로 검증합니다.
이 검증은 **실제 네이버 DOM 환경을 대상으로 하지 않습니다.**

## 단 한 번의 현장 종합 검증

1. PC 크롬에서 네이버 검색어 396요금제를 검색해 **검색 수집**과 **현재 화면 위치 검수**를 실행합니다.
2. 같은 검색어로 모바일 기기에서 동일하게 수집하고, 검수 화면에서 실제 보이는 제목/블록을 전부 확인합니다.
3. 블로그·카페·웹문서 3개 이상을 직접 방문하여 본문 분석용으로 저장합니다.
4. 패턴 관측은 다른 검색어를 포함한 충분한 표본을 확보한 뒤 실행합니다.
5. 대조군 변경 실험은 수정 전 2건·수정 후 2건 수집과 실제 수정/대조 문서가 있어야 합니다.
   수정하지 않은 자료에 대해 실험이 완료됐다고 표시할 수 없습니다.
6. **1~5단계 전체 검증하기** → JSON 보고서 저장. 시각 검수 PNG도 별도로 저장합니다.

현장 자료가 없다면 단계 3·4 또는 5를 완료로 표시하지 않는 것이 정상입니다.
특히 하루 안에 7일간의 글 수정 전후 결과를 실제로 확보했다고 주장해서는 안 됩니다.

공유할 보고서에는 검색어·문서 URL과 검색 화면 요소 등이 포함되므로 공개 전 확인하세요.
네이버의 내부 알고리즘 점수나 실시간 공식 검색 순위를 조회하지 못합니다.
