# SERP Lens v2.4 — 네이버 검색어·제목 관측

## 목적
네이버 블로그 제목 공식이나 순위 가중치를 추정해 확정하지 않는다. **같은 게시글이 어떤 검색어에서 발견되는지**와 네이버 검색 화면에 **어떤 제목으로 표시되는지**를 함께 수집하여 가설을 검증한다. 기존 공개 네이버 본문 수집(최대 6건)은 유지한다.

## 비교 요청
비공개 GitHub 저장소 `prepaid1215/serp-lens-private-data`의 이슈에 `serp-lens-request` 라벨을 적용:

```text
SERP_LENS_TITLE_COMPARE_V1
{"queries":["KT 바로유심 개통","바로유심 개통방법","편의점 KT 유심"],"limit":6}
```

- 사용자가 승인한 실행 환경(켜진 Chrome + SERP Lens + 유효한 브라우저 세션 토큰)이 필요하다.
- 한 요청에 **중복되지 않은 2~4개 검색어**만 입력한다. 길이 2~70자.
- 검색어는 네이버 일반 PC 통합검색 URL `where=nexearch`에 직접 전송된다.
- 요청당 본문 성공 수집 목표 1~6건, 게시글 방문 후보 최대 12건. 1일 이슈 요청은 최대 8건.
- 로그인, CAPTCHAs 또는 우회 수집 없음.

## 산출물

1. 각 검색어의 `serp-lens/searches/YYYY-MM/*.json`
   - `result_title`: 검색 화면에서 추출하거나 추정한 표시 제목.
   - `title_confidence`: `high`는 제목형 링크 자체, `medium`은 일반 앵커 텍스트, `heuristic`은 가까운 카드 제목 추정, `unverified`는 신뢰할 만한 제목 추출 실패.
   - `document_visual_order`: 읽힌 화면의 **게시글 링크들**을 화면 Y 좌표로 정렬한 순서 후보. 실제 통합검색 순위 / 블로그 탭 순위 / 유기적 검색 순위가 아니다.
   - `source_visual_order`: 읽힌 링크 중 블로그 또는 카페별 화면 Y 순서 후보.
   - `block_heading_hint`: 가까운 영역의 표제 텍스트 *추정*. 빈 문자열이면 확인되지 않음.
   - `observed_y_px`: 검색 결과 화면의 문서 Y 좌표. 크롬 뷰포트·확장 로드·결과 변형에 영향을 받음.
2. 수집 가능한 게시글 본문 최대 6개 `serp-lens/pages/YYYY-MM/*.json`.
3. 작업 이슈의 완료 댓글
   - `query_comparison.counts`: 검색어별 확인된 **개별 게시글 링크 후보 수**.
   - `query_comparison.overlaps`: 같은 게시글 URL을 두 검색어에서 모두 확인한 후보 수.
   - `query_comparison.repeated_articles`: 반복 확인된 게시글과 쿼리별 표시 제목·관측 위치.
   - `article_summaries[].observed_queries`: 확보한 본문에 대한 검색어별 관측 정보.
   - `title_disagreement`: 신뢰도 'unverified' 외 표시 제목이 문서 제목과 문자열상 일치하지 않는 경우의 **추정 신호**. 실제 네이버 제목 재작성 여부를 확정하지 않음.

## 실사용 검증 및 v2.4.1 보정
- 2026-11-05 실사용 #11: 검색어 3개, 수집 본문 6개, 검색어 간 중복 링크 관측 성공.
- 문제 발견: 인접한 네이버 카드의 블로그명/카페명을 글 제목으로 잘못 추정하여 6개 글 모두 `title_disagreement=true`라는 거짓 양성 발생.
- v2.4.1에서는 제목 링크 자체 또는 **동일 게시글 URL에 연결된 제목 링크**만 확인된 표시 제목으로 인정한다. 계정 이름 및 `새 창 열림` 안내 문구는 제목으로 채택하지 않는다.
- 미확인 검색 제목은 `title_confidence=unverified`, `result_title=''`; 직접 수집한 실제 게시글 제목(`article_summaries.title`)은 별도로 유지한다.
- 검색 제목이 확실하지 않을 때 `title_disagreement=null`로 표시한다. **null은 일치한다는 의미가 아니라 검증 불가**이다.

## 제약 사항
- 네이버의 실제 모바일 검색 순위, 광고/스마트블록 경계, 공식 랭킹 점수 또는 클릭률은 관측하지 않는다.
- 검색 페이지에서 로드되지 않은 항목이나 UI 구조 변형으로 누락된 글이 있다.
- 카페의 slug URL과 숫자 ID URL이 서로 다른 형태로 나타나면 중복 집계가 발생할 수 있다.
- 정확히 같은 게시글과 검색어도 개인화, 시각, 로그인 상태에 따라 결과가 다르다.
- 일회성 비교는 원인/결과를 증명하지 않는다. 같은 환경에서 날짜별 반복 관측과 반례가 필요하다.
- 인식 실패를 순위 0이나 미노출 확정으로 해석해서는 안 된다.

## 하위 호환
