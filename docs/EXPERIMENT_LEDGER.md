# NAVER Rank Lab — 변경 전후 대조군 실험실 (v1.7 beta)

## 실제로 무엇을 하는가

네이버의 비공개 순위 산식이나 C-Rank/D.I.A. 내부 점수를 추출하는 도구가 아닙니다.
사용자가 **직접** 네이버 검색 결과를 저장하고, 게시글의 변경 전후 노출 순서를 기록해
같은 검색어·기기에서 수정하지 않은 대조 문서와 비교하는 **관측 실험 도구**입니다.

## 실험 방법

1. 네이버에서 검색어를 PC 또는 모바일로 직접 검색하고 SERP Lens로 **변경 전** 자료를 수집합니다.
   가능한 같은 조건으로 최소 두 번 이상 수집하고 보이는 화면 캡처로 DOM 순서를 수동 검증하세요.
2. 블로그 또는 웹페이지 **한 개의 요인만** 수정합니다. 예: 제목만 수정하고 본문·이미지·내부링크는 유지.
   실제 수정한 날짜와 시간을 기록합니다.
3. 같은 검색어로 노출되는 다른 문서 1~5개의 URL을 대조 문서로 정합니다.
   대조 문서는 수정하지 않을 계획이어야 합니다. 확장프로그램은 수정 여부를 자동으로 확인하지 못합니다.
4. Intelligence 대시보드 **변경 전후 실험실**에서 실험 이름, 변경 유형, 검색어, 기기, 실제 수정 시각,
   실험 문서 URL, 대조 문서 URL, 변경 내용과 대조군 선정 근거를 저장합니다.
5. 수정 후에도 같은 키워드·기기에서 검색 결과를 직접 수집합니다.
   수정일 기준 전후 **3/7/14/30일** 관측 기간을 선택할 수 있습니다.
6. **전후·대조군 비교**를 실행합니다. TXT 보고서 또는 JSON 증거 파일을 받아 ChatGPT 분석에 활용하세요.

## 측정 방식

- 같은 검색어와 기기에서만 수집 기록을 가져옵니다.
- 광고가 아닌 문서 결과의 **HTML DOM 추정 순서**를 추적합니다. 실제 화면 위치나 공식 순위가 아닙니다.
- 변경 시각 이전과 이후 각각의 관측창 안에서 실험 문서와 대조 문서의 **발견된 위치의 중앙값**을 계산합니다.
- 각 문서의 변화 = 변경 전 위치 중앙값 - 변경 후 위치 중앙값; 양수이면 더 앞쪽에 관측됨.
- 대조군 상대 변화 = 실험 문서 변화 - 동일 문서 유형의 대조 문서 변화 중앙값.
- 검색 결과에 등장하지 않은 문서는 위치를 **null(미등장)**로 두며 다른 순위를 만들지 않습니다.
- 실험 문서와 문서 유형이 다른 대조 문서는 상대 변화 계산에서 제외합니다.
- 전후 각각 2회 이상, 비교 가능한 대조 문서 1개 이상이면 반복 관측 수집 기준을 충족한 것으로 표시합니다.
  이는 통계적 유의성을 뜻하지 않으며 결과를 유의하다고 판정하지 않습니다.
- 수집 전후 시점·문서 유형·위치·변화·검색 화면 출처 URL·원본 수집 해시를 보고서에 포함합니다.

## 주의

- 네이버 검색의 블록 배치, 개인화, PC/모바일 차이, 유사 키워드 검색 의도, 시간 흐름 등의 요인이 교란할 수 있습니다.
- 문서가 관측 결과에 없다면 수집된 검색 화면에서 **미등장**한 것이지 색인 제외 또는 순위 하락 확정이 아닙니다.
- 대조군을 수정하지 않았다는 것은 사용자가 입력한 계획일 뿐 자동으로 검증되지 않습니다.
- 변화량을 비교했다고 해서 수정한 내용이 결과의 원인임을 뜻하지 않습니다.
- 네이버 검색 결과를 자동 대량 호출하거나 캡차를 우회하는 기능은 없습니다.
- 새 기록은 로컬 브라우저 IndexedDB에만 보관합니다. **검색 기록 최대 2,500건, 방문 문서 500개, 실험 기록 150개**입니다.
  오래된 기록은 각 한도에 도달하면 자동 정리됩니다. 기존 SERP Lens의 HTML/PNG 원본은 최신 1개만 보관합니다.
- 확장프로그램 삭제·브라우저 프로필 교체·설치 경로 변경에 따라 로컬 데이터가 사라지거나 분리될 수 있습니다.
  중요한 실험 결과는 TXT/JSON을 내려받아 따로 보관하세요.

## 구현과 테스트

- extension/experiment-lab.js: URL 정규화, 대조군 및 전후 관측창 비교, 증거 텍스트
- extension/intelligence-store.js: 기존 데이터 보존하며 IndexedDB v1 → v2 스키마 마이그레이션
- extension/intelligence.html + intelligence.js + intelligence.css: 입력 폼, 비교 화면, 보고서
- tests/experiment-lab.mjs: 관측창, 문서 유형, 누락 결과, 상대 변화 테스트
- tests/browser_intelligence.py: Chromium 전체 이용 흐름 스모크 테스트
