## 실제 네이버 저장 HTML 대조

보유한 2026-10-10 원본 HTML 20개에 대해 비공개로 검사했다. 주요 세 키워드의 PC/모바일 상위 10개 문서 유형은 앞서 저장된 집계와 각각 일치하였다.

| 키워드 | 웹 | 카페 | 블로그 | 지식iN |
|---|---:|---:|---:|---:|
| 선불폰 개통 | 0 | 5 | 4 | 1 |
| 선불폰 개통방법 | 0 | 7 | 3 | 0 |
| 선불폰 셀프개통 | 1 | 4 | 5 | 0 |

일부 지역 키워드는 이전 수집 요약과 독립적으로 재대조가 필요하다. 광고 링크(ad redirect)가 일반 결과에 포함되는 문제는 수정했다. 사용자 보유 원본 HTML·PNG·개인정보/타인 계정은 공개 소스에 포함하지 않는다.

**한계:** 보유한 원본 데이터는 오늘의 실시간 SERP가 아니며 네이버 색인 여부를 나타내지 않는다. 현재 실제 웹 화면 순위는 스크린샷과 사용자가 확인해야 한다. `web/engine.js`가 DOM 구조로 추출한 결과가 모든 시점·기기에 대해 정확하다고 주장하지 않는다.

## 오프라인 웹 테스트 특이사항

격리된 시험 환경에서 브라우저의 localhost/file URL 직접 이동이 관리 정책으로 차단되어, Chromium about:blank 문서에 소스와 UI를 삽입하여 기능을 검증했다. HTTPS/localhost 보안 컨텍스트의 Web Crypto SHA-256은 Node 기반 엔진과 실제 배포 환경에서 별도 확인이 필요하다. 임시 브라우저 시험에서는 검증용 더미 다이제스트를 주입했으므로 화면 캡처의 `0000…` 해시를 실제 해시로 취급하지 않는다.
