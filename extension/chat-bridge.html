HOW TO USE

이 채팅에서 이렇게 요청하세요

네이버에서 'KT 바로유심 개통', '바로유심 개통방법', '편의점 KT 유심'을 비교 조사해 줘. SERP Lens 제목 비교로 검색 화면의 표시 제목, 공통 게시글, 검색어별 차이를 정리해 줘.

비교 요청은 최대 4개 검색어와 공개 게시글 본문 최대 6개입니다. 실제 검색 순위가 아니라 관측한 링크 화면 위치를 기록합니다.

요청은 GitHub를 통해 전달됩니다. 완료 전에 이 채팅이 자동으로 새 답변을 보내는 방식은 아닙니다.
