로컬 자료를 읽는 중입니다.

1. 공유할 로컬 자료 선택

네이버 검색 수집과 ‘현재 문서 분석용 저장’으로 확보된 자료입니다. 체크하지 않은 내용은 전송하지 않습니다. 로그인·개인정보가 포함된 문서는 공유하지 마세요.

게시글 본문 0

전송할 본문과 검색 결과 직접 보기 






2. 별도 비공개 GitHub 저장소 연결


첫 연결에만 설정합니다. 기존 공개 코드 저장소에 게시글 자료를 올리지 마세요. 전송에는 사용자가 발급한 해당 저장소 전용 Fine-grained PAT(Contents 읽기/쓰기)가 필요합니다.














확인을 누르기 전에는 네트워크 요청을 보내지 않습니다.











자동 조사 · 이 채팅에서 검색 요청 실행


한 번 설정하면 이 채팅의 GitHub 연결로 전용 검색 작업을 등록할 수 있습니다. Chrome이 실행 중일 때 확장프로그램이 작업을 확인하고, 네이버 검색과 공개 블로그·카페 게시글을 최대 3개까지 직접 열어 수집합니다. 사용자가 개별 글을 열 필요는 없습니다.










자동 조사 상태 확인 중…


Chrome이 열려 있고 연결 토큰이 유효해야 합니다. 별도 비공개 저장소에 Issues 읽기/쓰기 및 Contents 읽기/쓰기 권한이 필요합니다. 요청당 최대 3개 공개 글, 하루 최대 8건이며 로그인 우회·CAPTCHA 우회는 하지 않습니다.






3. 이 ChatGPT 채팅에서 자료 조회하기


전송 성공 후에는 ChatGPT에 연결된 GitHub 앱에서 비공개 저장소를 읽을 권한을 부여해야 합니다. ChatGPT가 직접 수집한 자료를 읽는 것은 별도 권한이며, 전송만으로 자동 연결되지는 않습니다.



비공개 자료 인덱스 보기


지금 구현된 방식은 ‘저장된 자료 다시 읽기’입니다. ChatGPT에서 새로운 검색어만 입력해 네이버를 자동으로 방문·수집하려면, 추가로 인증된 원격 검색·수집 서버가 필요합니다.




모든 전송은 사용자 확인 후 수행됩니다. 원본 HTML, 화면 스크린샷, GitHub 토큰은 게시글 JSON에 포함하지 않습니다.
