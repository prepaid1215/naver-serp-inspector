SERP LENS · CHAT BRIDGE

네이버 ↔ ChatGPT 연결

ChatGPT가 기록한 검색 요청을 검토한 뒤 실행하고, 결과를 비공개 저장소로 전달합니다.

연결 준비 중입니다.

1. GitHub 비공개 저장소 연결

기존 SERP Lens 소스 저장소와 별개인 비공개 저장소를 사용합니다. GitHub 토큰에는 그 저장소에 대한 Contents 읽기·쓰기 권한만 부여하세요. 토큰은 이 화면의 메모리에만 보관하며 브라우저 저장소나 보고서에 넣지 않습니다.

비공개 저장소가 아니면 연결하지 않습니다. 로그인·캡차 우회 기능은 없습니다.

2. ChatGPT 검색 요청 실행

요청은 GitHub의 bridge/requests/<요청ID>.json에 저장됩니다. 요청마다 실행 버튼을 눌러야 새 검색 탭과 최대 10개 글을 방문합니다. 현재 버전은 PC 네이버 블로그·카페만 지원합니다.

연결 후 요청 목록이 표시됩니다.

3. 본문 확인 후 ChatGPT로 전달

수집할 때 네이버 검색 탭과 게시글 탭이 임시로 열리고, 처리가 끝나면 닫힙니다. 수집한 내용은 자동으로 업로드하지 않습니다.

아직 실행한 요청이 없습니다.

현재 버전의 한계

이것은 ChatGPT 자체 검색 엔진에 네이버를 추가하는 기능이 아닙니다. 사용자의 GitHub 연결을 통한 요청·응답 방식입니다. 새 요청마다 사용자가 확장프로그램에서 실행을 승인해야 하며, 본문이 없는 글이나 지원되지 않는 페이지는 누락 사유를 남깁니다. 공개 저장소 업로드, 계정정보 수집, 백그라운드 무제한 크롤링은 지원하지 않습니다.

검색 결과는 참고용 · 네이버 공식 순위 아님 · 외부 사이트 및 로그인 제한 글은 수집하지 않음
