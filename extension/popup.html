현재 네이버 검색 화면
검색 페이지 확인 중…

먼저 네이버에서 원하는 검색어를 검색한 뒤 이 아이콘을 눌러 주세요.

네이버 검색결과 페이지에서만 사용할 수 있습니다.

검색은 자동으로 실행하지 않습니다. HTML은 현재 열린 탭에서 읽으며 PNG는 현재 보이는 화면만 저장합니다. 위치 검수 캡처는 별도로 최대 24개 보관하며, 수집 전에 계정·개인정보가 화면에 없는지 확인하세요. 스크롤 아래쪽까지 담은 전체 화면 캡처는 아닙니다.

사용자가 클릭한 페이지의 자료만 로컬에 저장하며 자동 업로드하지 않습니다.
